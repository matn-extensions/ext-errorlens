# ErrorLens Inline Diagnostics

Displays compiler and linter warnings/errors inline with highlighted category badges

## Details
- **Identifier**: `matn.ext.errorlens`
- **Version**: `1.0.0`
- **Category**: `linters`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **ErrorLens Inline Diagnostics**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-errorlens
```
